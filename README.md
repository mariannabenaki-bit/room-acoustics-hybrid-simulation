# room-acoustics-hybrid-simulation
Simulation of room acoustics using hybrid model in Pyroomacoustics

The model combines the Image Source Model and the Ray Tracing model to produce realistic BRIRs, using HRTFs from SADIE II database (KEMAR).
The batch code produces binaural signal for many different testing scenarios.

The HRTF sofa file is too big to deposit, but you can find it at: https://www.york.ac.uk/sadie-project/database.html
